# Anusha Dagar Portfolio

This is my personal portfolio. I built it to share my experience in applied AI, backend engineering, and banking technology as I look for software engineering opportunities in Vancouver and across Canada.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The live site is available at https://anusha-dagar-portfolio.anusha-dagar-portfolio.workers.dev/.
